Created: 2026-09-04 (America/Los_Angeles)

## Outcome
Connect a personal learning note to reviewed Agent experience and its actual task evidence, with useful navigation in both directions.

## Acceptance
- Personal practice notes save/clear without changing shared insights, candidate content or observation metadata; legacy progress reads without migration.
- Accepted Learning candidates open the exact scoped Library item; linked tasks open their original project.
- Library displays an explicit source → confirmed experience → exposure → feedback path, revision identity counts, and paginated Run evidence.
- Different scopes/projects never merge. Unknown references are excluded. Missing or corrupt evidence cannot hide healthy Library content.
- Browser navigation, unsaved-note preservation, scope isolation, privacy, typecheck and relevant tests pass; standalone packaging still works.

## Boundaries
Preserve the previous uncommitted stage. No graph dependency, full frontend framework migration, automatic memory approval, observation enablement, or deployment. Evidence is project-local and never proves adoption or causality.
