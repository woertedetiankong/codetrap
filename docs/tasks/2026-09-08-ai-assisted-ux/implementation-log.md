# Decisions

- Keep the existing workbench and add a task card instead of a second chat client. The copy boundary is explicit; nothing is auto-sent or auto-saved.
- Existing HTML is attached to Learning. Other tasks expose Learning/Experience/both destinations. Prompts retain source coverage, ASCII examples, real IDs and human review.
- Drafts are scoped to project and retained only in page memory. Desktop/mobile mounts synchronize without persisting source text to local storage.
- Use native selects/details, large controls, focus-visible outlines, instant press response, reduced motion and stronger-contrast support.
- Rename quality scores to content checks and explain that they do not verify facts. Identify all-session totals separately from current-session counts.
- Preserve the JSON error envelope and add typed recovery for missing import fields and version conflict; add a read-only artifact schema command. Other errors remain compatible.
