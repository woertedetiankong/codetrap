# Decisions

### 2026-09-08 — Optional history is an explicit installation choice

Move the old history-review skill outside the default plugin skill directory.
Fresh setup installs three defaults; --with-review opts in, default setup
preserves the new review entry if already installed, and --without-review archives
it. Legacy learning-review is archived instead of silently opting existing
seven-skill users into the new optional entry.

### 2026-09-08 — Preserve source contracts and user customizations

Keep one external-source procedure under study references, available to the
co-installed capture entry. Destination intent precedes extraction. Store detailed
confirmed-memory and HTML procedures as references. Explicit static assets serve
both source and standalone setup, including reference-file currency checks.
Known retired skill directories move outside discovery to unique backup paths;
changed active skills are copied to backup before update. Other skills remain untouched.
